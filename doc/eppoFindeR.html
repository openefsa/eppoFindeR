eppoFindeR

Overview

Welcome to the eppoFindeR vignette! This package is a wrapper around the public APIs of the European and Mediterranean Plant Protection Organization (EPPO) database. It offers a convenient and efficient way to access a wide range of information on plant pests, diseases, and species using R, making it an invaluable tool for researchers and practitioners in plant protection.

Prerequisites

To use the package, ensure you have a stable internet connection, as it will not work otherwise. The package communicates with the EPPO database online services to fetch and manipulate data, so a reliable connection is essential.

Installation

You can install the eppoFindeR package from CRAN with the following command:

# install.packages("eppoFindeR")

Or, if you are installing from Azure DevOps:

# install.packages("devtools")
# devtools::install_github("yourusername/eppoFindeR")

Basic Usage

The primary functionality of eppoFindeR is to retrieve data about EPPO codes. Users have two main options: 1) only fetch data from a specific service, or 2) fetch all data from the database (i.e. query all available services).

For example, to query the categorization service for the “BEMITA” EPPO code, you can use the queryTheEPPOForService() function.

library(eppoFindeR)

result <- queryTheEPPOForService("BEMITA", service = "categorization")
#> https://data.eppo.int/api/rest/1.0/taxon/BEMITA/categorization?authtoken=be5e3dacce514cd0527cd6f76b7774d8
print(result)

Alternatively, you can query the entire EPPO database, which means performing a search across all the available services. The result will be a list of data frames, each corresponding to a different service (e.g. pests, plants, diseases etc.).

The eppoFindeR package also includes a data wrangling function that helps combine the data fetched from the taxonomy and rank services, thus allowing for a more comprehensive and integrated data retrieval.

Assume ‘taxonomy’ and ‘kingdom’ are two dataframes obtained from querying the corresponding EPPO services:

taxonomy <- queryTheEPPOForService("BEMITA", service = "taxonomy")
#> https://data.eppo.int/api/rest/1.0/taxon/BEMITA/taxonomy?authtoken=be5e3dacce514cd0527cd6f76b7774d8
kingdom <- queryTheEPPOForService("BEMITA", service = "kingdom")
#> https://data.eppo.int/api/rest/1.0/taxon/BEMITA/kingdom?authtoken=be5e3dacce514cd0527cd6f76b7774d8

# Wrangle data to combine taxonomy and rank
wrangled_data <- taxonomyRanked(taxonomy, kingdom)
print(wrangled_data)
